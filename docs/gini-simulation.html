About the Simulation Suite

The Autophage Protocol includes a comprehensive Python simulation suite that validates the economic model's predictions. The suite implements Monte Carlo simulations, agent-based modeling, and statistical analysis to demonstrate how metabolic token dynamics create more equitable wealth distribution compared to traditional economies.

Key Implementation Details

The simulation validates Theorem 2.1 from the litepaper: "Under the Autophage Protocol with exponential decay and activity-based token generation, the Gini coefficient converges to G ∈ [0.08, 0.11] for populations n ≥ 100."

Token Decay Implementation

Each token species has decay rates calibrated to biological persistence:

# Token decay rates from Table 1 of the paper
self.decay_rates = {
    TokenSpecies.RHYTHM: 0.05,      # 5% daily, half-life ~13.5 days
    TokenSpecies.HEALING: 0.0075,   # 0.75% daily, half-life ~92 days
    TokenSpecies.FOUNDATION: 0.001,  # 0.1% daily, half-life ~693 days
    TokenSpecies.CATALYST: 0.05      # 5% daily (simplified)
}

# Whale protection (Section 3.4)
def apply_whale_protection(self, balance: float, species: str) -> float:
    """Apply progressive decay rates for whale protection"""
    if species != TokenSpecies.RHYTHM:
        return self.decay_rates[species]
    
    # Progressive decay tiers for Rhythm tokens
    if balance <= 10000:
        return 0.05  # 5% base rate
    elif balance <= 50000:
        return 0.075  # 7.5%
    elif balance <= 100000:
        return 0.10   # 10%
    else:
        return 0.15   # 15%

# Token generation (Section 3.3)
def generate_rewards(self, active_users: np.ndarray, species: str) -> np.ndarray:
    """Generate token rewards for active users"""
    rewards = np.zeros(self.n_users)
    μ, σ = self.reward_params[species]
    
    # Determine participants
    n_active = active_users.sum()
    participation_rate = self.participation_rates[species]
    n_participants = int(n_active * participation_rate)
    
    # Generate rewards (non-negative normal distribution)
    if n_participants > 0:
        participant_indices = np.random.choice(
            np.where(active_users)[0], 
            size=n_participants, 
            replace=False
        )
        raw_rewards = np.random.normal(μ, σ, size=len(participant_indices))
        rewards[participant_indices] = np.maximum(0, raw_rewards)
    
    return rewards

Gini Coefficient Calculation

The Gini coefficient measures wealth inequality using the standard formula:

def calculate_gini(self, balances: np.ndarray) -> float:
    """Calculate Gini coefficient (Section 4.1: Wealth Distribution)
    
    Uses the standard Gini coefficient formula:
    G = Σᵢ₌₁ⁿ Σⱼ₌₁ⁿ |xᵢ - xⱼ| / (2n² μ)
    """
    if np.sum(balances) == 0:
        return 0.0
    
    # Sort balances
    sorted_balances = np.sort(balances)
    n = len(sorted_balances)
    
    # Calculate Gini using the efficient formula
    index = np.arange(1, n + 1)
    return (2 * np.sum(index * sorted_balances)) / (n * np.sum(sorted_balances)) - (n + 1) / n
