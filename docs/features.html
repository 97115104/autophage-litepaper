Core Protocol Features

Mandatory token decay creates an economy where value must circulate rather than accumulate. Proof of Temporal Persistence (PoTP) solves health incentives, privacy verification, and sustainable economics simultaneously.

Four token species provide temporal diversity matching health's natural rhythms. Rhythm tokens implement 5% daily decay mirroring cardiovascular fitness deterioration. Healing tokens use 0.75% daily decay acknowledging therapeutic timelines. Foundation tokens apply 0.1% daily decay reflecting preventive care's lasting impact. Catalyst tokens employ dynamic decay adjustment to maintain marketplace balance.

The dual-balance Reservoir manages both token and USDC flows through mathematical homeostasis. Three-tier liquidity system ensures healthcare access regardless of market conditions. Dynamic energy gradients between 1.2× and 3.0× create counter-cyclical stability.
